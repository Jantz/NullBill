                      1. 
              
              
                        
                
                        OAuth client
                        
                
                        Each setup run uses it to put the policy below in place, which lets you and nobody else reach the server. Setup stops if Tailscale refuses it.
                        
                
                        How to get it
                  
                        Sign in to the Tailscale admin console with your Tailscale login from Setup. Under Settings, Trust credentials, add an OAuth client with the scope Policy file set to write, and the scopes the console adds to it. Paste its client ID and secret here.
                        
                
                        
                
                        An OAuth client is saved. Paste a new one to replace it.
                        
                
                        
                  
                  
                
                        
                
                        
                  
                  
                        
                
                        
              
                        
            
                        2. 
            
                      2. 
              
              
                        
                
                        Auth key
                        
                
                        Joins the server to your tailnet. It is used once, then forgotten. Make it after a setup run with the client above, since that run defines the tag tag:nb-vpn; then run setup again.
                        
                
                        How to get it
                  
                        In the Tailscale admin console, under Settings, Keys, press Generate auth key. Leave Reusable and Ephemeral off, turn on Pre-approved and Tags with tag:nb-vpn, and press Generate key.
                        
                
                        
                
                        A key is saved. The next setup run uses it once to join, then forgets it.

                      Home network
                      
            
          
                      
          
                      Once you reach this page over Tailscale, close Proxmox's web UI and SSH to your home network, so only Tailscale gets in. If you do not press Keep it closed on this page, opened over Tailscale, within 15 minutes, the server opens it again by itself, so a mistake cannot lock you out.                       Agents
                      
            
                      Sign in the coding agent on the server, choose what it may do, and give agents elsewhere a narrow token.
                      
          
                      
        
                      
        
                      
          
          
                      You have not chosen AI agents under Setup, What to run. This page matters once you do.
                      
        
                      

        
                      
          
                      
            
                      Coding agent sign-in
                      
            
          
                      
          
                      
            
                      Paste an Anthropic API key or a Claude subscription token. It is kept encrypted on this server and shown to nobody.
                      
            
                      How to get a subscription token
              
                      On a computer where you use Claude Code with a Pro, Max, Team or Enterprise plan, run claude setup-token and paste the token it prints. It lasts a year.
                      
            
                      
            
                      
            
            
                      
              
              
                      
            
                      
          
                      
        
                      

        
                      
          
                      
            
                      Let the agent manage the server
                      
            
          
                      
          
                      With this on, the agent in the operator container gets root on Proxmox. It can find and fix problems, update Proxmox and the services, and run setup and Update NullBill itself. It asks you before anything that deletes data, such as removing a guest, a disk or a backup, and each setup run or update it starts is announced on your alert topic. Turning it off takes its key off Proxmox at once.
                      
          
                      How it is logged
            
                      Every command the agent runs is logged before it runs. See agent-access.md to read the log or talk to the agent.
                      
          
                      
          
                      
            
            
                      
          
                      
          
                      
            
            
                      
              
                      Give the agent root on Proxmox? It can then change anything on the server. You can take it away here at any time.
                      
              
                      
                
                
              
                      
            
                      
          
                      
        
                      

        
                      
          
                      
            
                      Fixes as pull requests
                      
            
          
                      
          
                      
            
                      Optional. When the agent finds a bug in NullBill, it can propose the fix on GitHub for you to merge. Save the token, then run setup so the agent gets it.
                      
            
                      How to make the token
              
                      On GitHub, open Settings, Developer settings, Personal access tokens, Fine-grained tokens and press Generate new token. Pick Only select repositories with NullBill's repository, and under Repository permissions set Contents and Pull requests to Read and write.
                      
            
                      
            
                      
            
            
                      
              
              
              
                      
            
                      
          
                      
        
                      

        
                      
          
                      
            
                      Agents on other computers
                      
          
                      
          
                      A coding agent elsewhere, such as on your laptop, can run the checks and read their output over Tailscale, and nothing else. Name it and the page shows its token once; revoke it here when it is done.
                      
          
                      For a computer not signed in to Tailscale as you
            
                      That computer needs to join your tailnet with an auth key tagged tag:nb-agent, which reaches only this page. The calls the agent makes are in agent-access.md.
                      
          
                      
          
                      This needs a plan with Tailscale first: read the hardware and save your choices under Setup.

Keep it like a password.
