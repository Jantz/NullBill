                      Access
                      How you reach the server from your own devices, and only from them.
                      
      
                      
        
        
        
        
      
                      

      
                      
        
                      Status
                      
        
                      Your server joins your free Tailscale network, so this page and your services open from your devices anywhere, and from nothing else.
                      
        
                      
          
                      
            
                      1OAuth client
                      
              
                      Each setup run uses it to put your access policy in place. In the Tailscale admin console: Settings, Trust credentials, add an OAuth client with Policy file and DNS, both write. DNS makes names such as forgejo.nullbill.internal work on your devices.

                      Names on your devices
                      Names such as forgejo.nullbill.internal work once a setup run had DNS on the client. On Android, set Settings, Private DNS to Automatic if it names a provider; on Linux, run sudo tailscale set --accept-routes --accept-dns. Addresses keep working either way.

                      Status
                      
        
                      Your SSH public keys let you into the workspace as root and push to Forgejo as your own user, from each device that holds the matching private key. The next setup run puts them in place; taking one off here takes it off there too.
                      
        
                      
          
                      
            
                      Your public keys
                      
              
                      One per line, as in the .pub file. To make one on your device, run ssh-keygen -t ed25519, then show it with cat ~/.ssh/id_ed25519.pub (on Windows, in PowerShell: type $env:USERPROFILE\.ssh\id_ed25519.pub).

                      How closing works
                      Once this page opens over Tailscale, close Proxmox's web UI and SSH to your home network. Then press Keep it closed here, over Tailscale, within 15 minutes, or the server opens it again by itself, so a mistake cannot lock you out.

                      Agent
                      What the agent may do, how it signs in, and everything it did.
                      
      
                      
        
        
        
      
                      
      
                      

      
                      
        
                      
          
                      
            
                      Sign-in
                      
              
                      An Anthropic API key, or a Claude subscription token from claude setup-token. Kept encrypted on the server; the agent itself never sees it.
                      
              
                      
            
                      
              
              
                      
              
                      Where do I get one?
                
                      Claude Pro or Max: on any computer with Claude Code, run claude setup-token and paste what it prints; it lasts a year. API: make a key at console.anthropic.com; that works from a phone too.
                      
            
                      
          
                      

          
                      
            
                      Access mode
                      
              
                      What the agent may run without asking you.
                      
              
                      Blocked in every mode: erasing disks, deleting backups, reading secrets, silencing the command log, and touching the NullBill container.
                      
            
                      
              
                      
                
                
                
              
                      
              
              
                      
            
                      
          
                      

          
                      
            
                      Operator agent
                      
              
                      A second agent for long work, in the operator container. Root lets it run any command on Proxmox, setup and updates, each announced on your phone. Off removes its key at once.
                      
            
                      
              
                      
                
                      
              
                      
            
                      
          
                      

          
                      
            
                      Fixes as pull requests
                      
              
                      Optional. A fine-grained GitHub token for NullBill's repository, with Contents and Pull requests read and write, lets the operator agent propose fixes. Run setup after saving.
                      
              
                      
            
                      
              
              
                      
            
                      
          
                      

          
                      
            
                      Agents on other computers
                      
              
                      A token that lets an agent elsewhere run the checks and read their output over Tailscale, and nothing else.
                      
            
                      
              
                      
                
                
              
                      
              
                      
              
                      
                
                      Shown once. Keep it like a password.
