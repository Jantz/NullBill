      2. Look at the hardware

      3. Choose what to run

      Other disks

      Disks besides the one Proxmox runs from, as the probe found them. Nothing happens to a disk you leave alone. Keeping a disk from your old PC shares its files to you over Tailscale, read-only unless you allow changes. NullBill does not back a kept disk up, so keep a copy of anything you cannot lose. See legacy-disk.md.

      Your kept disks

      Once setup has run, open these from a device signed in to your Tailscale, as user . Windows: File Explorer's address bar. macOS: Finder, Go, Connect to Server. Linux: your file manager's Other Locations.

          7. Reach it from anywhere
          
      
          Optional. Your server joins your free Tailscale network, so this page and your guests are reachable from your own devices wherever you are. Until then everything stays on your local network.
          
      
            
        
          1. Sign in to the Tailscale admin console with the login you gave in step 3. Under Settings, Trust credentials, add an OAuth client with the scope Policy file set to write, and the scopes the console adds to it. Paste its client ID and secret below. Setup uses it to put the policy below in place each run, and stops if Tailscale refuses it; the policy lets you, and nobody else, reach the server.
            2. 
        
          2. Run setup once, so the policy, which defines the tag tag:nb-vpn, is in place. Then under Settings, Keys, press Generate auth key. Leave Reusable and Ephemeral off, turn on Pre-approved and Tags with tag:nb-vpn, and press Generate key.
            3. 
        
          3. Paste the key here and run setup again. The server uses it once to join, then forgets it.

          Agents on other computers
          
      
          A coding agent elsewhere, such as on your laptop, can run the checks and read their output over Tailscale, and nothing else. Name it and the page shows its token once; revoke it here when it is done. An agent on a computer that is not signed in as you needs that computer on your tailnet with an auth key tagged tag:nb-agent, which reaches only this page. See agent-access.md for the calls.

            9. Close the home network
            
      
            Once you reach this page over Tailscale, close Proxmox's web UI and SSH to your home network, so only Tailscale gets in. If you do not then press Keep it closed on this page opened over Tailscale within 15 minutes, the server opens it again by itself, so a mistake cannot lock you out. Once closed, this page also answers only over Tailscale and on the on-site screen.
