                                  Access
                                  Who reaches the server: you from your own devices, and the people you add, each only what you tick for them.
                                  
      
                                  
        
        
        
        
        
      
                                  

      
                                  
        
                                  Status
                                  Path
                                  
        
                                  
        
                                  Your server joins your free Tailscale network, so this page and your services open from your devices anywhere, and from nothing else.
                                  
        
                                  
          
                                  
            
                                  1OAuth client
                                  
              
                                  Each setup run uses it to put your access policy in place. In the Tailscale admin console: Settings, Trust credentials, add an OAuth client with Policy file and DNS, both write. DNS makes names such as forgejo.nullbill.internal work on your devices. With Users, write, too, removing a person under People also removes their Tailscale account.

                                  A key waits for the next setup run.
                                  
            
                                  
              
              
                                  
            
                                  
          
                                  
          
                                  
            
                                  Home router
                                  
              
                                  A phone on mobile data connects directly only when your home router sends UDP port 41642 to the server. The server asks it for that port by itself. Switch this off if you forward the port yourself, or want no port open: the server cannot see a forward it did not ask for.
                                  
            
                                  
              
              
                                  
            
                                  
          
                                  
        
                                  
        
                                  Names on your devices
                                  Names such as forgejo.nullbill.internal work once a setup run had DNS on the client. On Android, set Settings, Private DNS to Automatic if it names a provider; on Linux, run sudo tailscale set --accept-routes --accept-dns. Addresses keep working either way.
                                  
        
                                  Direct and relayed connections
                                  A device connects to the server directly when it can, and through Tailscale's relays when it cannot. Relays are slower, and video stutters. A phone on mobile data connects directly only when your home router sends UDP port 41642 to the server. The server asks your home router for that every quarter of an hour, with UPnP or NAT-PMP; a router that has both switched off needs one switched on, or the port forwarded by hand. A router that is itself behind your provider's shared address cannot open a port at all, and such devices stay on relays. The Tailscale app shows which it is: open the server's entry there and look for Direct or Relayed. After a change on the home router, Run the checks in the Run setup menu reads it again.
                                  
        
                                  The Tailscale policy setup puts in place
                                  
      
                                  

      
                                  
        
                                  Status
                                  
        
                                  Friends and family join your Tailscale network with their own account and open only the services you tick for them, from their own devices. Tailscale holds them to it, and a change is in force within seconds.
                                  
        
                                  What a person can and cannot do
          
                                    
            
                                  • They can use each service you tick, from their own devices, the way anyone uses a website or joins a game server. A tick opens that service's port and nothing more.
                                    • 
            
                                  • They cannot log in to the server or to a container: no shell, no root. This page, Proxmox, the services you did not tick and your own devices do not answer them.
                                    • 
            
                                  • Inside a service they are what its own account makes them, such as a Jellyfin viewer or a Minecraft player. They are an admin there only if you make them one.
                                    • 
            
                                  • If a shared program has a security hole, someone you gave it to could misuse it. The program runs in a container or VM of its own, which has no rights on the server and reaches only what the firewall allows.
                                    • 
          
                                  
        
                                  
        
                                  
          Tailscale's access policy is not the one this page made: someone changed it in Tailscale, or a change did not arrive. Until it is sent again, people may open more or less than listed here.

                                    3.

                                  How closing works
                                  Once this page opens over Tailscale, close Proxmox's web UI and SSH to your home network. Then press Keep it closed here, over Tailscale, within 15 minutes, or the server opens it again by itself, so a mistake cannot lock you out.

                                  Agent
                                  What the agent may do, how it signs in, and everything it did.
                                  
      
                                  
        
        
        
      
                                  
      
                                  

      
                                  
        
                                  
          
                                  
            
                                  Sign-in
                                  
              
                                  An Anthropic API key, or a Claude subscription token from claude setup-token. Kept encrypted on the server; the agent itself never sees it.
                                  
              
                                  
            
                                  
              
              
                                  
              
                                  Where do I get one?
                
                                  Claude Pro or Max: on any computer with Claude Code, run claude setup-token and paste what it prints; it lasts a year. API: make a key at console.anthropic.com; that works from a phone too.
                                  
            
                                  
          
                                  

          
                                  
            
                                  Access mode
                                  
              
                                  What the agent may run without asking you.
                                  
              
                                  Blocked in every mode: erasing disks, deleting backups, reading secrets, silencing the command log, and touching the NullBill container.
                                  
            
                                  
              
                                  
                
                
                
              
                                  
              
              
                                  
            
                                  
          
                                  

          
                                  
            
                                  Operator agent
                                  
              
                                  A second agent for long work, in the operator container. Root lets it run any command on Proxmox, setup and updates, each announced on your phone. Off removes its key at once.
                                  
            
                                  
              
                                  
                
                                  
              
                                  
            
                                  
          
                                  

          
                                  
            
                                  Fixes as pull requests
                                  
              
                                  Optional. A fine-grained GitHub token for NullBill's repository, with Contents and Pull requests read and write, lets the operator agent propose fixes. Run setup after saving.
                                  
              
                                  
            
                                  
              
              
                                  
            
                                  
          
                                  

          
                                  
            
                                  Agents on other computers
                                  
              
                                  A token that lets an agent elsewhere run the checks and read their output over Tailscale, and nothing else.

Keep it like a password.
