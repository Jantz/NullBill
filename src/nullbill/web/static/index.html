          Agent

          Sign in

          An Anthropic API key, or a Claude subscription token from claude setup-token. Kept encrypted on the server; the agent itself never sees it.

          Access

          Always blocked, in every mode: erasing disks, deleting backups, reading secrets, silencing the command log, and touching the NullBill container.

          Operator agent

          A second agent for long work, in the operator container, used from the Proxmox shell or by remote agents. With this on it gets root on Proxmox and may run setup and updates; each run is announced on your phone. Off takes its key off Proxmox at once.

          Fixes as pull requests

          Optional. A fine-grained GitHub token for NullBill's repository (Contents and Pull requests, read and write) lets the operator agent propose fixes. Run setup after saving.

          Agents on other computers

          A token that lets an agent elsewhere run the checks and read their output over Tailscale, and nothing else.

          Shown once. Keep it like a password.

                        Tailscale
                        
        
                        Your server joins your free Tailscale network, so this page and your services work from your own devices anywhere.
                        
        
                        
          
                        
            
                        1OAuth client
                        
            
                        Each setup run uses it to put your access policy in place. In the Tailscale admin console: Settings, Trust credentials, add an OAuth client with Policy file and DNS, both write. DNS makes names such as forgejo.nullbill.internal work on your devices.
                        
            
                        Saved. Paste a new one to replace it.
                        
            
            
            
                        
          
                        
          
                        
            
                        2Auth key
                        
            
                        After one setup run with the client: Settings, Keys, Generate auth key, Pre-approved on, tag tag:nb-vpn. Used once, then forgotten; run setup again.
                        
            
                        A key waits for the next setup run.
                        
            
            
                        
          
                        
        
                        
        
                        On your devices, names such as forgejo.nullbill.internal work once a setup run had DNS on the client. On Android, set Settings, Private DNS to Automatic if it names a provider; on Linux, run sudo tailscale set --accept-routes --accept-dns. Addresses keep working either way.
                        
        
                        The Tailscale policy setup puts in place
                        
      
                        

      
                        
        
                        Home network
                        
        
                        Once this page opens over Tailscale, close Proxmox's web UI and SSH to your home network. Press Keep it closed here, over Tailscale, within 15 minutes, or the server opens it again by itself, so a mistake cannot lock you out.
                        
        
                        
        
                        
          
          
          
          
                        
        
                        
      
                        

      
                        
        
                        Trust this server, install the app
                        
        
                        Browsers warn on this page, Proxmox, Forgejo and Grafana because their certificates come from your server, not from a company browsers already know. The connection is encrypted either way. Install your server's root certificate once on each device: the warnings stop, and your phone can install this page as an app. It vouches only for your server's own addresses and names, never for any other website.
                        
        
                        
          
                        
            Download root certificate
            
                        The first setup run makes it.
                        
            
                        
            
                        Proxmox gets this certificate at the first setup run after you close the server to the home network. For the local AI model in a browser extension such as Page Assist, use the gateway's address, https://10.42.4.21:4000/v1 on most servers (Services shows yours), not its name. Jellyfin uses plain HTTP inside Tailscale's encryption, so browsers mark it "Not secure" in the address bar but show no warning page.
                        
          
                        
          
                        
            
                        Android
              
                          
                
                        1. On the phone, press Download root certificate.
                          2. 
                
                        2. Open Settings and search for CA certificate. On most phones it is under Security and privacy, More security settings, Install from device storage. Tap CA certificate, then Install anyway, and pick nullbill-root.crt from Downloads.
                          3. 
                
                        3. Open this page in Chrome again and choose Install app. If Firefox still warns: in Firefox open Settings, About Firefox and tap the Firefox logo until it says the debug menu is on. Back in Settings, open Secret Settings, turn on Use third party CA certificates, then close Firefox and open it again.
                          4. 
              
                        
            
                        
            
                        Windows
              
                          
                
                        1. Press Download root certificate and open the file.
                          2. 
                
                        2. Press Install Certificate, choose Current User, then Place all certificates in the following store, Browse, Trusted Root Certification Authorities. Press Next, Finish, and Yes to the warning.
                          3. 
                
                        3. Close the browser and open it again. Edge, Chrome and Firefox all use it.
                          4. 
              
                        
            
                        
            
                        iPhone and iPad
              
                          
                
                        1. Open this page in Safari, press Download root certificate and allow the download.
                          2. 
                
                        2. Open Settings, Profile Downloaded and press Install.
                          3. 
                
                        3. Open Settings, General, About, Certificate Trust Settings and turn on NullBill browser CA. Add the page to the Home Screen from the share menu.
                          4.
