# Code of conduct

Everyone who takes part in NullBill's issues, pull requests and
discussions is expected to be respectful and constructive.

- Be kind and assume good intent. Critique code and ideas, not people.
- No harassment, insults, discrimination or sexualised content, and no
  publishing anyone's private information.
- Stay on topic and keep disagreements technical.

## Enforcement

The maintainer may edit, hide or remove comments, close issues and pull
requests, and block accounts that break these rules. To report a problem,
use GitHub's **Report content** on the comment or issue concerned. For
something that should stay private, ask for a private channel the way
[SECURITY.md](SECURITY.md) describes.

This code is adapted from the
[Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.
